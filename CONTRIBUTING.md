# Contributing to mCLOUD

mCLOUD is a personal project, shared as is. It is maintained on free time, so there is no guaranteed response time.

## Reporting a bug

- Use the bug report form and fill in every field: version, macOS, cloud service, cache mode, steps to reproduce.
- One problem per issue. Several unrelated problems in one report are hard to follow and will be split or closed.
- Check you are on the [latest release](https://github.com/starbudweiser/mCLOUD/releases/latest) first.
- Remove passwords, tokens and private paths from logs and screenshots.
- Reports that can be reproduced are fixed first. A diagnosis or a suggested patch is welcome, but a clear way to reproduce matters more.

## Suggesting a feature

Describe the problem you want to solve. Features that add a lot of code or dependencies, or that do not fit a simple Finder-drive app, may be declined.

## Pull requests

Open an issue first for anything beyond a small fix. Keep changes focused; the interface text must stay translated in the four languages already present (French, English, Spanish, Italian).

Please be courteous: repeated pings on an issue do not speed it up.
